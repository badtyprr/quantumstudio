Visual circuit composer

The preview's File menu contains Open circuit, Save circuit, and Export OpenQASM. Its Examples menu contains a Bell states submenu, Teleportation, Bit-flip correction, Phase estimation, Grover search, and Bernstein–Vazirani presets. Use the zoom slider (25–150%) to inspect gates, or Fit wires to see the full register vertically. Long circuits scroll horizontally. On small windows, the editor itself scrolls to keep editing and calculation controls reachable.

Measurement and feedback help and Equivalent expression expand when needed. Collapsing them gives the diagram more room. Zoom, scrolling, and expanded details affect only the view and are not saved in .qcircuit files.

Choose Compose a circuit in the sidebar. The editor starts with a Bell pair and supports 1–8 qubits with up to 64 gate steps. Gates execute left to right; q0 is the first tensor factor. Select a gate, enter comma-separated wire indices (controls first), and choose Add gate. Rotation angles accept expressions such as pi/2. Remove the last step, clear the circuit, or restore the Bell example. Changing the register size starts a new circuit.

Load into calculator transfers the generated indexed-gate expression for evaluation. The diagram is a visual editor for the listed gates; it does not import arbitrary circuit images or quantum programs. Use Save circuit and Open circuit for editable .qcircuit files. Saved files preserve the register, gate order, wires, and angle expressions. Invalid files leave the current circuit unchanged. Unsaved edits are temporary.

Build a circuit as an expression

Available gates: I X Y Z H S T CNOT CX CZ SWAP CCX Toffoli CSWAP. Use Rx(θ), Ry(θ), Rz(θ), or P(θ) with radians. Global phases are preserved. Apply the rightmost operator first.

Ordering: the leftmost tensor factor is subsystem 0. In apply(U,state,[0,2]) the first gate wire maps to subsystem 0, the second to subsystem 2. This differs from Qiskit's least-significant-qubit indexing. Tensor product, multiplication, and division share precedence and associate left to right; parentheses make intent clear.

U(theta,phi,lambda) and U3(theta,phi,lambda) are general single-qubit gates using the explicit Qiskit UGate matrix convention. U2(phi,lambda) fixes theta to pi/2; U1(lambda) equals P(lambda). TeX forms such as U_{3} work too. For example, U2(0,pi) is H and U1(pi/2) is S. All angles use radians and global phases are retained.

Editing and exporting circuits

Select a numbered step above the diagram to edit its gate, wires or angles. Update gate replaces it in place; Cancel edit keeps the original. Invalid edits leave the circuit unchanged. Editing also works at the 64-step limit. Move earlier and Move later reposition the selected gate; Delete selected removes it. Moves keep pending field edits until Update gate. Moves and deletions take effect immediately; Cancel edit does not undo them.

Export OpenQASM writes an OpenQASM 3 program using standard gates. fSim takes two comma-separated angles; U3 takes three. iSWAP, FSWAP, fSim and U3 export as equivalent standard-gate sequences with their phases retained. FSWAP exchanges adjacent fermionic modes; use adjacent FSWAP sequences for nonadjacent mode permutations.

Reset and Measure return ensemble density matrices. M1-X and M1-Z measure the first listed wire and conditionally correct the second; M0 variants act on result zero. The Teleport example uses measurement feedback. These calculations return ensemble results, not randomly sampled shots.

Undo and Redo restore up to 100 committed circuit changes, including moves, deletions, register size, opening files and loading examples. New changes clear redo history. Pending field text is discarded when restoring a circuit. History lasts for this composer window only.

Controls and interactions

Square-root gates and fractional powers

sqrt(X), X^(1/2), and \sqrt{X} give SX. sqrt(SWAP) is a matrix square root, and applying it twice gives SWAP. Global phase is retained, so SX differs from Rx(π/2). Use parentheses around repeated powers: (X^(1/3))^3.

Square matrices up to dimension 64 are supported. Diagonal matrices and small self-inverse matrices have exact formulas; general numerical unitary or Hermitian matrices use approximate spectral powers. Thus sqrt(H*S) gives an approximate gate, and sqrt((I+X/2)/2) gives a density-matrix square root. The principal branch uses argument +π at −1. General nonnormal matrices, symbolic numerical-path exponents, and singular inverse roots are not supported. See the research note for tolerances and branch-cut limits.

ECR is the echoed cross-resonance gate, defined here as (X⊗I − Y⊗X)/√2 in leftmost-first order. ECR |00⟩ gives (|10⟩−i|11⟩)/√2. Its two circuit operands are ordered and labeled 0 and 1 on the diagram; reversing them changes the operation. OpenQASM export uses S, SX, CNOT and X with the global phase −π/4 retained. This matches Qiskit's physical operand order after accounting for its little-endian matrix convention.

controlled(U,n,s) adds n leading control qubits and activates U on the decimal control state s. The defaults are one control and all controls equal to 1. For example, controlled(X,2,1)|010⟩ gives |011⟩. Use controlled(X,1,0) for a control on 0. C(U,n,s) is an alias. The leftmost control is the most significant bit; use apply to select or reorder wires.

Named gates also include CY CH CCZ. Rxx(t), Ryy(t), Rzz(t), and Rzx(t) mean exp(−it(A ⊗ B)/2), with tensor factors in the written order. For example, Rxx(pi/2)|00⟩ is (|00⟩ − i|11⟩)/√2. Controls support 1–8 control qubits and a resulting matrix up to 512 × 512.

Textbook aliases also work: R_x(t), R_{XX}(t), and corresponding Y, Z, YY, ZZ, ZX subscripts. C^2(X) or C^{2}(X) means two controls, equivalent to Toffoli. To square a single-controlled operator instead, write (C(X))^2.

XXPlusYY(θ,β) rotates |01⟩ and |10⟩; XXMinusYY(θ,β) rotates |00⟩ and |11⟩. Other basis states are unchanged. β defaults to zero in expressions; the circuit composer takes both angles in radians. Negate θ for the inverse. For example, XXMinusYY(pi/2,pi/2)|00⟩ creates a Bell state. The first operand is the leftmost qubit; phase signs follow this ordering. Both gates support circuit editing, saving, and OpenQASM export.

Binary control patterns

controlled(X,2,"01") activates X when the leading controls are 01. A quoted control pattern must contain exactly one binary digit per control, including leading zeroes, with no spaces. The leftmost bit refers to the first control. The numeric-mask form remains available: controlled(X,2,1) is equivalent.

Equatorial rotations

R(theta,phi) rotates through theta about the equatorial axis cos(phi)X+sin(phi)Y. Angles are in radians: R(t,0)=Rx(t) and R(t,pi/2)=Ry(t). The circuit editor offers R with two comma-separated parameters. Its OpenQASM export uses Rz(-phi), Rx(theta), then Rz(phi), preserving the full matrix and global phase.

Algorithm building blocks

State reflections: reflection(ψ) is I−2Pψ, with Pψ the normalized projector onto a nonzero ket. It flips ψ's sign and leaves orthogonal states unchanged. Thus reflection(|++⟩) is minus the uniform diffusion operator. Try probs(-reflection(|++⟩)reflection(|11⟩)|++⟩) for one exact Grover iteration. phase_reflection(ψ,θ) applies phase exp(iθ) to ψ and leaves its orthogonal complement unchanged. θ is real and in radians; θ=π gives the sign flip. These functions accept numeric kets with 2–512 amplitudes, normalize internally, and reject zero or mixed states.

Pasted large operators: Unicode ∑, ∏, ⨂, and ⨁ accept the same explicit bounds and braced operand as their LaTeX forms. For example, ∑_{k=0}^{3}{k^2} gives 14. The large tensor/direct-sum symbols differ from binary ⊗ and ⊕.

Indexed block operators: \bigoplus_{k=0}^{1}{X^k} or blocksum(X^k,0,1,k) builds CNOT from blocks I and X. Blocks run in increasing index order. Scalars are 1×1 blocks; rectangular matrices form a block-diagonal linear map, rather than concatenated state vectors. The same finite bounds and index rules as tensorproduct apply.

Indexed tensor products: \bigotimes_{k=0}^{2}{Ry(k*pi)} or tensorproduct(Ry(k*pi),0,2,k) puts factors in increasing index order, left to right. Use inclusive integer bounds and a symbolic index. At most 32 factors are supported within the matrix-size limit; reversed bounds and infinite products are rejected. Brace the TeX operand.

Tensor powers: write H^{\otimes 2} or H ^ { \otimes 2 }. Kets, bras, and operators are supported; <i|^{\otimes 2}|11> gives −1/2. Exponents must be integers from 0 through 10, within the matrix-size limit. Spaces around dagger, transpose, and conjugation superscripts are accepted too.

Grover search: choose Examples → Grover search → Mark 00, 01, 10, or 11. The editable two-qubit circuit marks the chosen target with a phase oracle and amplifies it in one iteration. Load into the calculator for 100% ideal target probability. The gate sequence returns −|target⟩, preserving its global phase in state results and OpenQASM export. These examples start with a known marked target; they do not search an external database.

Bell preparations: choose Examples → Bell states for Φ+, Φ−, Ψ+, or Ψ−. Each preset is an editable two-qubit circuit. It starts with H on q0 and CNOT from q0 to q1, then adds X on q1 for Ψ states and Z on q0 for the minus sign. The State view shows the relative phase; probability bars alone cannot distinguish the plus and minus states. Save/open, undo/redo, and OpenQASM export preserve these preparations.

Logical XOR: use a xor b, ⊻, or \veebar. Zero is false and nonzero is true; the result is 1 when their truth values differ. AND binds before XOR, then OR. phase_function(x>=2 xor x mod 2,2,x) is Z⊗Z. Applying it to |++⟩ followed by H⊗H recovers |11⟩. The integer function xor(5,6) still gives 3; use explicit * to multiply its result. ⊕ remains matrix direct sum.

LaTeX physics macros: \expval{Y}{i} gives 1; \matrixel{0}{X}{1} gives 1. Aliases include \ev, \mel, \dyad, \op, and \ip. A single-label dyad forms a projector; a single-label inner product gives its squared norm. Sizing stars are accepted. Expectations require an explicit state label; no global state is assumed.

Nested predicates: parentheses preserve Boolean subexpressions when comparing their 0/1 results. For example, (0=0)!=(1=0) is 1. phase_function((x=1)!=(x=2),2,x) equals Z⊗Z.

Boolean predicates: combine conditions with and, or, not, or ∧, ∨, ¬. TeX logical commands work too. Comparisons bind before NOT, then AND, XOR, then OR; use parentheses to change grouping. For example, phase_function(x=1 or x=3,2,x) equals I⊗Z. Logical results are 0 or 1. Group predicates when embedding them in arithmetic, such as 1+(not 0).

Comparison predicates: use =, ==, !=, <, >, ≤, or ≥; TeX comparison commands work too. True and false evaluate to 1 and 0. Chained ranges such as 1 ≤ x < 3 require both comparisons to hold. Try phase_function(x=3,2,x) to mark |11⟩. Equality compares; it does not assign. Group a predicate before multiplying it by a state, as in (2<3)|0⟩.

Phase oracles from formulas: phase_function(f(x),n,x) puts the sign (−1)^f(x) on each basis state, without an output ancilla. Write the arithmetic expression directly: phase_function(floor(x/3),2,x) equals CZ and marks only |11⟩. Every result must be 0 or 1; widths are 1–9 qubits. Constant 0 gives I and constant 1 gives −I, preserving global phase. This is an explicit dense matrix.

Expression-defined oracles: oracle_function(f(x),n,m,x) builds the reversible matrix mapping |x,y⟩ to |x,y XOR f(x)⟩. Write the expression itself, for example oracle_function(bitdot("101",bits(x,3)),3,1,x). Inputs and outputs use n and m bits, with positive widths and at most 9 total qubits. Every function result must fit the output register. This enumerates an explicit dense matrix; it does not synthesize a hardware gate sequence.

Fixed-width bits: bits(5,4) gives [0,1,0,1], most significant bit first. bitvalue("00101") returns 5. Both use exact integers and compose with bitxor and bitdot. Widths are 1–1024; negative values, fractional values, and overflow are rejected. The integer result has no width metadata, so specify the width when converting back.

Fourier dimensions: Textbook QFT_4, Unicode QFT₄, and TeX \mathrm{QFT}_{4} mean the transform on four basis states, equivalent to fourier(4) or QFT(2). The subscript is a dimension; the parenthesized QFT argument is a qubit count. Dimensions 1–64 are supported, including non-powers of two. Group a dimension expression in braces, as in QFT_{2^2}. Dagger gives the inverse.

Finite sums and products: TeX \sum_{k=0}^{2} k and Unicode ∑_{k=0}^{2} k give 3. An unbraced body includes the following multiplication, division, and tensor factors, stopping before a top-level addition, subtraction, comparison, or argument separator. Thus \sum_{k=0}^{2} k+1 gives 4, while \sum_{k=0}^{2} (k+1) gives 6. Use braces or parentheses to specify a larger body. Nested sums, finite products, tensor products, and direct sums follow the same rule.

Subscripted bit labels: Inside a sum, |a_1 a_0⟩ denotes two computational bits, with a_1 on the left. Separate the subscripted indices and any literal 0 or 1 bits with spaces. For example, sum(sum(|a_1 a_0⟩,0,1,a_1),0,1,a_0)/2 gives [1;1;1;1]/2. Bras and TeX \ket{a_1 a_0} work too. Each index must evaluate to 0 or 1; at most ten bits are supported. A single named ket retains its existing meaning; use |a_0⟩_2 for a computed single-bit index.

Binary exclusive-OR: bitxor("101","110") gives the bit vector [0,1,1]. Its alias is binaryxor. The result retains the input length and can feed directly into bitdot or another bitxor. A one-bit result displays as a scalar. Inputs follow the same strict binary validation as bitdot; the existing integer xor keeps its meaning. Outside basis labels, ⊕ remains a matrix direct sum. Inside literal binary labels, |001 ⊕ 101⟩ equals |100⟩; TeX \ket{001\oplus 101} works too. Bras, chains and comma-separated registers are supported. Operands must have equal widths of 1–10 bits; symbolic labels such as |y⊕f(x)⟩ require an explicit oracle instead.

Binary inner product: bitdot("101","110") returns 1: it adds the pairwise bit products modulo 2. Use it in phase expressions such as (−1)^bitdot("101","100"). The alias binarydot and numeric row/column vectors also work. Inputs must have equal lengths, contain only 0 and 1, and have 1–1024 bits; quoted leading zeros are preserved.

Build an editable binary-map circuit: in the composer choose Build → From binary matrix…. Paste an invertible 1–8 bit matrix, with rows separated by new lines or semicolons. Rows are output bits, columns input bits, q0 first. It creates CNOT/SWAP steps and replaces the circuit; Undo restores the previous one. Invalid input preserves the circuit. The composer supports 64 steps. Prepare inputs before the synthesized gates to explore their action.

Binary maps as gates: linear_gate(A) maps |x⟩ to |Ax mod 2⟩ for invertible binary n×n A, with 1–9 qubits. Rows are output bits, columns input bits; q0 comes first. linear_gate([1,0;1,1]) is CNOT. Compose binary maps with gf2_mul(A,B) (B acts first), or invert with gf2_inverse(A). The gate is a dense calculator matrix, not a synthesized editor circuit.

Binary inverse: gf2_inverse(A) inverts square 0/1 matrices over GF(2), up to 128×128. It rejects matrices singular modulo 2. Use it to reverse a linear bit map; matrix products must be interpreted modulo 2. For example, gf2_inverse([1,1;0,1]) returns the same matrix.

Binary linear algebra: gf2_rref(A), gf2_rank(A), and gf2_nullspace(A) use exact GF(2) arithmetic. Enter 0/1 matrices up to 128×128; a flat vector is one equation. Nullspace basis vectors are columns; [] means only the zero solution. For Simon outcomes 010 and 101, gf2_nullspace([0,1,0;1,0,1]) gives the nonzero mask [1;0;1]. Multiple columns mean more independent equations are needed.

Simon’s algorithm: choose Examples → Simon’s algorithm and a three-bit hidden string. Six wires hold input q0q1q2 and output q3q4q5. For nonzero s, the four outcomes y satisfying bitdot(y,s)=0 each have probability 1/4. The 000 case is one-to-one and gives eight outcomes at 1/8. Repeated measurements and binary linear algebra are needed to recover a hidden string; one sample is insufficient. This preset displays the ideal marginal distribution and supports editing, save/open, undo/redo, and OpenQASM export.

Bernstein–Vazirani: choose Examples → Bernstein–Vazirani → Hidden string for any three-bit string. The four-qubit circuit prepares q3 in |−⟩, queries f(x) = s·x mod 2, then uses Hadamards to recover s on q0q1q2. Load into the calculator to see the selected three-wire marginal with 100% ideal probability at s. The visible CNOTs implement the chosen oracle; one oracle query may contain multiple gates. The editable circuit supports save/open, undo/redo, and OpenQASM export.

Phase estimation: choose Examples → Phase estimation · T gate in the circuit editor. The 14-gate circuit uses q0–q2 to estimate the phase of T on |1⟩ at q3. Click Load into calculator: its marginal-probability view shows outcome 1 (bits 001), meaning 1/8 of a turn. For another phase angle θ, edit the first three controlled-phase angles to 4θ, 2θ, θ. Phases not exactly represented by three bits produce a distribution over estimates.

Marginal probabilities inspects selected wires of pure or noisy circuits. Enter distinct wire indices separated by commas. Outcome bits follow the entered order; 2,1,0 reverses 0,1,2. Unselected wires are summed over. Selecting every wire is allowed.

Bit-flip correction

The composer offers two-bit feedback gates such as M10-X: measure the first two entered wires, then apply X to the third if their ordered bits are 10. Z variants also work. Every feedback step measures again. Bit-flip correction loads a five-qubit repetition-code example that recovers q0 after a single bit flip. Trace out wires [1,2,3,4] to inspect it. This code does not correct phase errors or general noise.

Bloch sphere

bloch(|i⟩) returns [x;y;z], the normalized Pauli expectations, and opens a sphere view in Quantum mode. It accepts a two-component ket or 2×2 density matrix and normalizes nonzero input. For a register, use bloch((|00⟩+|11⟩)/sqrt(2),0) to select wire 0 (leftmost). This reduced, maximally mixed state appears at the center. Validation applies to the reduced state; it does not certify an arbitrary full-register density matrix.

The circuit editor's Inspect selector loads State, Probabilities, Bloch qubit, Schmidt coefficients, or Marginal probabilities. For Bloch qubit, enter one wire index. For Schmidt coefficients, enter the wires on side A, separated by commas (for example 0,2); the remaining wires form side B. Both sides must contain a wire. Schmidt inspection requires a pure state vector and excludes circuits containing measurement, reset, feedback, or noise. The selected view and partition are not saved in circuit files. Inspection leaves the circuit unchanged, so you can compare different views of the same operations.

The coordinates retain exact arithmetic where possible. The projection, length and purity readouts are approximate. Rotate the view with the arrow buttons; Reset view restores the initial angle. Pure states have vector length one, while mixed states lie inside. Finite numeric state entries are required; positivity checks use numerical tolerances, and approximate Hermiticity residuals are symmetrized.

Measurement charts

Calculations starting with probs(...) show a probability chart for 2–64 outcomes alongside the original result. Bar lengths and percentages are approximate. Outcome indices follow the returned vector order, including the subsystem order you chose for a marginal distribution. Choose Decimal or Binary outcome labels for power-of-two outcome counts; binary indices retain leading zeroes, such as 001. Switching labels changes only the chart labels. Other outcome counts use decimal labels. The preference lasts while the app is open and is not saved in sessions. Hover over a row for more digits; longer charts scroll.

Analyze a state

purity(state) returns 1 for a nonzero ket, or tr(ρ²)/tr(ρ)² for a density matrix. A reduced Bell qubit has purity 1/2. variance(A,state) computes the normalized second moment minus the squared normalized first moment and requires a Hermitian observable. For example, variance(Z,|+⟩) is 1 and variance(Z,|0⟩) is 0. These functions normalize scaled states but do not certify positivity. Zero norm or trace is rejected.

schmidt_coeffs(ψ,subsystems) returns the normalized pure state's Schmidt coefficients in descending order, including zeros. For example, schmidt_coeffs(3|00⟩+4i|11⟩,0) gives [0.8; 0.6]. Select one side of the bipartition; the other is its complement. A third argument gives qudit dimensions, as in schmidt_coeffs(ψ,0,[2,3]). The leftmost subsystem is 0. This returns coefficients, not basis vectors, and accepts column kets up to 1024 amplitudes, not mixed states. Numerical results below 10⁻¹⁴ are reported as zero; this does not certify exact Schmidt rank.

Operator norms: tracenorm(A), frobeniusnorm(A), and spectralnorm(A) accept numeric matrices, including rectangular ones. General norm(A,p) or schatten(A,p) uses Schatten order p≥1. Indexed bars ‖A‖₁ and ‖A‖₂ mean trace and Frobenius norms; ‖A‖_{infinity} means spectral norm. Here order 2 is Frobenius, not the induced matrix 2-norm. Results are approximate, with up to 1024 entries. Plain norm(ket) retains exact Euclidean behavior. These functions do not calculate the channel diamond norm.

Compact Pauli observables

pauli("XYZ") means X ⊗ Y ⊗ Z; Pauli(XYZ) also works. Prefixes such as -i retain global phase. Labels contain 1–9 uppercase I/X/Y/Z letters, with the leftmost letter acting on subsystem 0. Ordinary X Y remains matrix multiplication. Build Hamiltonians with weighted sums: pauli("XX")+pauli("YY")+pauli("ZZ") has expectation −3 in the singlet state.

Evolution and measurement

logm(U) gives a natural matrix logarithm. For unit-time evolution exp(−iH), H=i*logm(U) is a generator: evolution(i*logm(X),1)|0⟩ gives |1⟩. Exponentiating the logarithm reconstructs the gate, including its phase.

Logarithms are not unique. This function chooses arguments in (−π,π], including +π at −1. It supports square matrices up to dimension 64: diagonal and small self-inverse cases have exact formulas; general unitary or Hermitian cases are numerical. Singular matrices and general nonnormal matrices are unsupported. A recovered generator need not be the original physical Hamiltonian. See the research note for numerical tolerances.

probs(state,indices) returns probabilities for selected output wires, for kets or density matrices. The first selected wire is the most significant output bit. For example, probs(|100⟩,[2,0]) gives certainty for outcome 01. This calculates a distribution without sampling or collapsing the state.

evolution(X,t) computes exp(−itX), with hbar = 1. expm(A), exp(A), and e^(A) use the matrix exponential for matrix inputs. Exact reductions cover diagonal and quadratic cases; general numeric matrices up to 64 × 64 use scaling, Taylor expansion, and squaring. The app labels numerical results approximate.

probs(ρ) accepts density matrices. born(E,state) returns a normalized expectation; postselect(P,state) returns a normalized projected state and checks that P is a Hermitian projector. Zero-probability outcomes are errors. Supplied states and effects must be physically valid; positivity and POVM completeness are not certified.

A^T transposes, A^* conjugates, and A† does both. ptranspose(ρ,[0,2]) or ρ^{T_{0,2}} partially transposes selected qubits.

Mixed states and noise

apply(U,ρ,indices) evolves a density matrix as UρU† on the selected wires. For example, apply(S,density(|+⟩),0) produces density(|i⟩). Wire order follows the supplied indices, including nonadjacent wires. The operation does not normalize nonunitary branches; use postselect for normalized projection.

density(ψ) calculates ψψ†. tr(ρ) takes the trace. ptrace(ρ,1) traces out subsystem 1. For example:

ptrace(density((|00⟩+|11⟩)/sqrt(2)),1)

returns the maximally mixed single-qubit state. Use channel(ρ,vector(K0,K1)) for a Kraus sum. Use vector(...) for Kraus lists; bracket notation concatenates matrices in Qalculate!. normalize(ψ) normalizes a nonzero column ket. probs(ψ) normalizes squared amplitudes; density() and expect() do not silently normalize inputs.

For noise on selected wires, add indices: channel(ρ,vector(K0,K1),1). Complete amplitude damping uses vector([1,0;0,0],[0,1;0,0]); dephasing uses vector(I/sqrt(2),Z/sqrt(2)). On a Bell state, damping qubit 1 produces an equal mixture of |00⟩ and |10⟩. Indices may be reordered or nonadjacent. The sum is not automatically normalized, and channel completeness is not certified.

Without wire indices, channel also accepts rectangular Kraus matrices: each has n input columns and the same m output rows. The result is an m × m matrix, with n and m at most 512 and at most 256 operators. For example, channel(density(|1⟩),vector([1,0;0,1;0,0])) embeds a qubit into a qutrit. A one-dimensional output simplifies to a scalar: channel(density(|i⟩),vector(⟨0|,⟨1|)) returns 1 (discarding the system), while keeping only ⟨0| returns 1/2. Scalar inputs represent one-dimensional systems: channel(1,vector(|i⟩)) prepares density(|i⟩). Partial Kraus sums retain their probability weight. POVM effects P are not generally Kraus matrices; use born(P,state) for an effect's probability. The wire-indexed form still requires square operators.

Single-qubit noise

amplitude_damping(p), phase_damping(p), and depolarizing(lambda) return Kraus-matrix lists. Apply them with channel(density(|1⟩),amplitude_damping(3/4)), or add a zero-based wire index for a larger register. The same lists work with choi(amplitude_damping(3/4)) and superop(phase_damping(1/2)).

Damping parameters range from 0 to 1. Amplitude damping transfers population from |1⟩ to |0⟩. Phase damping preserves populations and multiplies off-diagonal coherence by √(1−p); it is not a phase-flip probability. Depolarization uses E(ρ)=(1−λ)ρ+λ Tr(ρ)I/2, with 0≤λ≤4/3. At λ=1 the qubit is fully mixed; λ=4/3 applies X, Y or Z with equal probability. Parameters must be finite real values without broad uncertainty. These constructors describe one qubit; local application does not automatically add noise to every circuit gate.

amplitude_damping(p,excited_population) models relaxation toward an equilibrium probability of |1⟩. Use phase_amplitude_damping(amplitude,phase,excited_population) to include extra dephasing; the third argument defaults to zero. All parameters lie in [0,1] and amplitude+phase must not exceed one. The resulting coherence multiplier is √(1−amplitude−phase). The optional population is a probability, not a temperature in physical units.

The circuit editor offers AD, GAD, PD, PAD, and Depol on one wire at a time. Select a noise type to see its parameter order and range. Amber blocks identify noise operations, and subsequent gates act on the resulting density matrix. Parameter expressions are evaluated when loaded into the calculator. Noise circuits support editing, reordering, undo/redo and .qcircuit save/open. The OpenQASM exporter currently rejects noise circuits explicitly; it never silently drops their channels.

Thermal relaxation

thermal_relaxation(T1,T2,time,p) constructs noise from relaxation times; p is the equilibrium excited population and defaults to zero. T1 and T2 must be positive (infinity is allowed), time finite and nonnegative, and T2≤2T1. Enter numeric times in a consistent unit. Population relaxes as exp(−time/T1); coherence decays as exp(−time/T2). The editor's Thermal operation takes T1, T2, time, p on one wire.

Channels and operator vectors

Use parentheses for operator expressions inside double brackets: |(X+iY)⟩⟩ means vec(X+iY), and ⟪(X+iY)|(X+iY)⟫ is 4. Nested states work too: |(density(|i⟩))⟩⟩ vectorizes a density matrix. Expression labels share the normal parser limits and preserve spaces inside quoted strings.

vec(A) stacks columns; unvec(v,rows) reverses it. Operator double-kets such as |Y⟩⟩ mean vec(Y). superop(vector(K0,K1)) gives the channel matrix acting on column-stacked density matrices. choi(vector(K0,K1)) gives the unnormalized Choi matrix in input ⊗ output order. Rectangular Kraus matrices are supported; completeness is not certified.

Pauli transfer matrices

ptm(amplitude_damping(3/4)) converts a Kraus list to a Pauli transfer matrix. Use ptm(vector(S)) for a unitary channel. For one qubit, rows and columns are ordered I, X, Y, Z; multiplying the augmented Bloch vector [1,x,y,z] gives its new coordinates. For multiple qubits, order is lexicographic: II, IX, IY, IZ, XI, … . The leftmost Pauli acts on the leftmost tensor factor. One to four qubits are supported. Supplied Kraus matrices are not normalized or certified trace-preserving.

paulivec(A) returns normalized Pauli coordinates Tr(PjA)/√d; unpaulivec(v) reverses the conversion. For a qubit density matrix, multiply the returned vector by √2 to obtain [1,x,y,z]. Both functions also work for arbitrary complex operators on one to four qubits, without normalizing their trace. To apply a channel, write unpaulivec(ptm(amplitude_damping(3/4))paulivec(density(|i⟩))). Ordinary vec(Y) retains column-stacking semantics.

Chi process matrices

chi(Kraus_list) (also Chi, χ, or \chi) returns a χ process matrix in the normalized Pauli convention: E(ρ)=Σ χijPiρPj/d. It supports one to four qubits in the same Pauli order as PTM. A trace-preserving channel has trace χ=d; for example, chi(vector(I)) is diag(2,0,0,0). Ordinary χ matrix multiplication does not compose channels. Supplied Kraus lists are not normalized or certified trace-preserving.

Left and right superoperators

spre(A), spost(B), and sprepost(A,B) act on column-stacked operators as AX, XB, and AXB. For example, unvec(sprepost(Y,S)vec(X),2) equals YXS. The right operator is transposed, not conjugated, in the superoperator matrix. Use sprepost(U,U†) for a unitary channel. Inputs support up to 16 rows and columns; spre/spost require square matrices, while sprepost allows rectangular ones.

Lindblad dynamics

lindblad_dissipator(C) constructs D[C](ρ)=CρC†−(C†Cρ+ρC†C)/2. liouvillian(H,vector(C0,C1,...)) adds these to −i[H,ρ], with ħ=1; omit the list for Hamiltonian evolution only. H must be Hermitian, and all operators have matching dimension 2–16. Put √rate in each collapse operator. The result is a generator: evolve with unvec(expm(t*liouvillian(H,Ks))vec(rho),d). General numerical propagation supports d≤8 because of the existing exponential size limit. This does not solve time-dependent master equations.

State fidelity

fidelity(a,b) returns squared state fidelity for normalized kets or density matrices, in dimensions up to 64. It is one for identical states and zero for orthogonal states; fidelity(|0⟩,|+⟩) is 0.5. This matches Qiskit state_fidelity. Results are numerical; near rank deficiency, square-root roundoff can reduce accuracy to about 1e-7 despite the displayed digits.

root_fidelity(a,b) (also rootfidelity) returns the unsquared value used by IBM's General Formulation of Quantum Information course. For example, root_fidelity(|0⟩,|+⟩) is approximately 0.707106781187. It uses the same normalization, physical-state checks, dimension limits and numerical accuracy as fidelity.

State distinguishability

tracedistance(a,b) compares kets or density matrices of matching dimension, up to 64. It normalizes both states and returns approximately 12 significant digits: zero for identical states, one for perfectly distinguishable states. For example, tracedistance(|i⟩,I/2) is 0.5. The numerical validity checks and precision limits match entropy.

Quantum entropy

Entanglement negativity

negativity(state,subsystems[,dimensions]) computes the sum of absolute negative eigenvalues of the normalized state's partial transpose. lognegativity(...) returns log₂(1+2N). A Bell pair has N=0.5 and logarithmic negativity 1; a product state has zero. Subsystem indices start at zero on the left. Qubit dimensions are inferred; use negativity((basis(0,6)+basis(4,6))/sqrt(2),0,[2,3]) for a qubit–qutrit state.

Both measures accept nonzero finite kets or physical density matrices with total dimension 2–64, normalize them, and return a double-precision approximation. Zero negativity does not prove separability in general: some entangled states have positive partial transpose. These measures complement entropy when analyzing noisy circuits.

entropy(state) returns von Neumann entropy in bits. Use entropy(state,e) for nats, or another finite real base greater than one as the second argument. A nonzero ket has zero entropy; entropy(I/2) is one bit. Density matrices are normalized by trace and checked numerically. Matrix entropy supports dimensions up to 64 and returns approximately 12 significant digits using double precision, regardless of calculator precision. See the research note for tolerances.

Qudits and mixed dimensions

ptrace(ρ,indices,[2,3]) and ptranspose(ρ,indices,[2,3]) specify a qubit–qutrit factorization, ordered left to right. The dimensions must multiply to the matrix size. For example, ptrace(density(|1⟩ ⊗ basis(2,3)),0,[2,3]) keeps the qutrit in its third basis state. Explicit dimensions support a total size up to 512. The two-argument forms continue to infer qubit dimensions.

shift(d) cycles basis j to (j+1) modulo d. clock(d) multiplies basis j by exp(2πij/d). fourier(d) is the positive-exponent normalized Fourier matrix. Shift and clock support dimensions 2–64; Fourier supports dimensions 1–64. At dimension 2 these are X, Z, and H. For example, shift(3) basis(2,3) wraps to basis(0,3). Numeric X/Z subscripts can label circuit wires, so dimensions use explicit function calls.

Qudits and subsystem order

Modular arithmetic: write 17 mod 5, 17\bmod 5, or mod(17,5) for residue 2. This works inside computed labels, such as |2*k\bmod 15⟩_16. Modulo has multiplication/division precedence; group an entire sum explicitly, as in (2+7) mod 3. In quantum mode, % also means modulo. Congruence annotations using \pmod are not accepted.

Comma-separated registers: |0,1⟩ is |0⟩ ⊗ |1⟩. Labels may contain whole registers or named states, such as |00,1⟩ and |+,i⟩. Bras and matrix elements work too: <1,1|CNOT|+,0⟩ gives 1/sqrt(2). For mixed dimensions, use individually dimensioned adjacent states such as |2⟩_3|1⟩.

Adjacent registers: |0⟩|1⟩ forms |01⟩. The kets group before a gate acts, so CNOT|+⟩|0⟩ prepares Φ+. Matrix elements also group adjacent input kets: <00|CNOT|+⟩|0⟩ gives 1/sqrt(2). Adjacent output bras work too: <1|<1|CNOT|+⟩|0⟩ gives 1/sqrt(2). Compact register inner products such as <i|<−|i⟩|−⟩ give 1, including complex conjugation of the bras. Bra–ket inner products and ket–bra outer products keep their usual meaning. Ordinary matrix juxtaposition still multiplies matrices; use ⊗ for arbitrary grouped state expressions.

Bell labels: |Φ+⟩ and |Φ−⟩ mean (|00⟩ ± |11⟩)/√2; |Ψ+⟩ and |Ψ−⟩ mean (|01⟩ ± |10⟩)/√2. Use one explicit sign. ASCII |Phi+>, Unicode |Ψ⁻⟩, and LaTeX \ket{\Phi^{+}} are accepted. Bras, overlaps, and density matrices use the same exact states.

Repeated-bit registers: |0^3⟩ means |000⟩, and |1³⟩ means |111⟩. Counts may be indexed expressions and must evaluate to integers from 0 through 10. Group compound counts, as in |0^(n+1)⟩. Zero copies give 1. An explicit dimension instead makes the label arithmetic: |1^3⟩_8 selects basis index 1.

Computed dimensions: |7⟩_{2^3} or |7⟩_(2^3) equals |111⟩. Group a dimension expression explicitly so its exponent stays inside the subscript. Dimensions may depend on an index in a finite sum or tensor product, and must evaluate to integers from 2 through 1024. Equivalent expressions such as 2^3 and 4+4 have matching dimensions.

Computed basis indices: with an explicit dimension, labels may be expressions: |k+1⟩_4 or |mod(5,3)⟩_3. Thus ∑_{k=0}^{3}{|k⟩_4}/2 prepares the uniform two-qubit state. Each index must evaluate to an integer in range. Without a dimension suffix, binary labels retain their original meaning.

|2⟩_3 is a qutrit basis state. An explicit dimension suffix interprets its label as a decimal index; without a suffix, numeric labels are binary qubit strings. SUM(3) adds the control value to the target modulo 3. permute(state,[1,0],[2,3]) exchanges a qubit and qutrit. Partial trace and partial transpose also accept explicit subsystem dimensions.

Angular momentum

Jx(j), Jy(j), Jz(j), Jplus(j) and Jminus(j) construct spin matrices for integer or half-integer j from 1/2 to 63/2, with ℏ=1. The basis runs m=j,j−1,…,−j; basis index k means m=j−k. For example, Jplus(1)basis(1,3) raises m=0 to m=1 with coefficient √2. Jx(1/2), Jy(1/2), Jz(1/2) equal X/2, Y/2, Z/2. These are observables and ladder operators; exponentiate a Hermitian component to obtain a rotation.

Subscript spellings J_x(j), J_y(j), J_z(j), J_+(j) and J_-(j) also work. Pasted TeX can use \hat{J}_{+}(1); the spin argument is still required.

Spin-half basis labels accept |↑⟩ = |0⟩ and |↓⟩ = |1⟩. Multi-qubit strings such as |↑↓⟩ preserve wire order. TeX can use \ket{\uparrow\downarrow}, and the same labels work in bras and overlaps.

Compact product labels also accept |++⟩, |+−⟩ and |0+⟩. Each character is one qubit, in tensor order. The special labels |i⟩, |+i⟩ and |−i⟩ remain single-qubit Y eigenstates; use explicit tensor products to combine those states.

Bosons and fermions

destroy(d), create(d) and numberop(d) construct truncated bosonic operators. Raising the top state returns zero; the commutator includes a boundary correction and is not the identity everywhere. fdestroy(modes,site) and fcreate(modes,site) include Jordan–Wigner parity strings, with site 0 leftmost. The Examples library demonstrates both the truncation boundary and fermionic signs.

Paste mathematical TeX

Quantum notation mode also accepts mathematical TeX fragments, including nested fractions and roots, bra/ket macros, and matrix environments. No TeX installation is needed.

Use a braced body for sums/products. Products place increasing-index terms from left to right. basis(k,d) specifies the dimension of an indexed basis family. Norm delimiters ‖ψ‖ and \lVert ψ\rVert are accepted. Unsupported TeX macros and optional matrix row spacing produce an explicit error.

Double-bar matrices accept an explicit norm index: \begin{Vmatrix}3&0\\0&4\end{Vmatrix}_1 gives trace norm 7. Use _{\mathrm{F}} for Frobenius or _{\infty} for spectral norm. A power may appear before or after the index: \lVert A\rVert^2_1 squares the trace norm. A double-bar matrix without an index remains ambiguous and is rejected.

Pasting expressions

Multiplication signs × ⋅ · ∙ ∗ work like *, and division signs ÷ ∕ ⁄ work like /. Try X×Y (iZ), Y×X (−iZ), or Rx(π∕2). Products retain their written matrix order. Use ⊗ for a tensor product. Division follows the same grouping as ordinary slash syntax, so 8÷2÷2 is 2. Symbols inside double-quoted labels are preserved.

Paste Unicode radicals directly: √X gives SX, ∛X is a cube-root gate, and ∜X is a fourth-root gate. They cover the following signed power: √X² means sqrt(X²), while (√X)² squares the root. Multiplication ends that scope: √9*4 is 12; use √(9*4) for 6. Group an adjoint as (√X)† when it should apply to the root.

All radicals in quantum mode use principal complex powers, so ∛(-8) is 1+i√3. The √ button inserts a radical at the cursor. Standard sqrt(...) and indexed TeX roots remain available.

Pasted expressions may contain line breaks, thin spaces, nonbreaking spaces, or other Unicode whitespace. A leading byte-order mark is accepted. If you explicitly type quantum: in Standard mode, leading whitespace is also allowed. Quoted strings are preserved during Unicode whitespace normalization. Pauli words separately ignore ASCII whitespace, so pauli("X Y") equals pauli("XY"); non-ASCII spaces inside a Pauli word are rejected.

Operator typography and parsing

Unicode integer powers work directly: X², H⁻¹, X¹² and (X+Z)². A superscript sign needs following digits. Use caret expressions for fractional or symbolic exponents.

Matrix elements group the whole operator between their bars: ⟨+−|X ⊗ X|+−⟩ equals −1, and ⟨0|X+Z|0⟩ equals 1. Extra parentheses around the operator are optional.

\hat{X} and \widehat{X+Y} preserve operator values and grouping. A hat does not define an unknown operator. Adjacent formatted names, such as \mathbf{X}\mathbf{Y}, remain separate factors. iY means i times Y, but iSWAP is its own gate. Powers bind to the gate: iY^2 means i(Y²), while (iY)^2 squares the whole product. Quantum function calls reject missing or extra arguments.

Exact and numerical evaluation

Save session writes the current draft, notation/evaluation modes, and up to 50 recent calculations to a .qsession file. Open session replaces the current workspace only after validating the file. It never runs expressions automatically. Restored history results are marked Saved; double-click an entry and Calculate to refresh it. Large history previews are shortened to 32768 characters, and files are limited to 8 MB. Saves are explicit; circuit editor state uses separate .qcircuit files.

The evaluation picker offers Exact arithmetic and Numerical. Exact is the default. Numerical mode uses 30-digit working precision and displays significant digits, which can be fewer than 30. The result badge identifies approximate values. Use this mode when an exact expression remains in terms of unsimplified complex roots. History recalls both notation and evaluation modes. Working precision is not a certified error bound.

Practical boundaries

This is a small-system, dense-matrix calculator. Basis labels allow up to 10 qubits; density construction up to 512 amplitudes; QFT up to 6 qubits. The GUI offers a 15-second, 1-minute, 3-minute, or 10-minute time allowance. Cancel stops the worker without adding a history entry. The allowance applies to each new calculation and is not stored in session files. History persists only when explicitly saved as a .qsession file; each calculation starts a fresh backend. The app does not run quantum hardware or general Q#/Python programs. OpenQASM imports compile supported static circuits into the editor; runtime feedback and pulse programs are not supported. It does not parse arbitrary LaTeX or diagrams, certify physical validity, or implement infinite-dimensional operator algebra.

Limited TeX aliases include \langle, \rangle, \vert, \otimes, \oplus, and ^{\dagger}. Explicit matrix columns use commas and rows use semicolons.

Import OpenQASM

In the circuit composer, choose File → Import OpenQASM. The bundled qBraid PyQASM compiler expands static OpenQASM 2/3 loops, subroutines and custom gates into editable steps. The current limits are 8 qubits and 64 compiled steps. Angles become numeric; registers follow declaration order with index zero first. The import menu lets you choose IBM/Qiskit’s U matrix or the published OpenQASM 3 U matrix, which includes an extra exp(iθ/2) phase. The choice also applies to controlled U. Lowercase u and u3 keep the IBM/Qiskit matrix. Controlled gphase preserves the full phase for one or two controls.

Measurements discard classical outcomes; inspect quantum-wire probabilities. Runtime classical feedback, timing and pulse programs are rejected. A failed import keeps your circuit intact. GPhase represents an overall state phase, independent of the displayed wire.

Primitive iswap imports directly. Its inverse, integer powers, and one positive or negative control preserve the full phase. A controlled iSWAP expands to phase gates, CCZ and CSWAP; inverse iSWAP uses iSWAP and two Z gates. Fractional powers and multiple controls are not yet imported.

Stabilizer codes

stabilizer_projector(vector(X@X,Z@Z)) gives the Bell-state code-space projector. stabilizer_dimension(vector(Z@Z@I,I@Z@Z)) returns 2 for the repetition code. stabilizer_syndrome(vector(Z@Z@I,I@Z@Z),I@X@I) returns [1 1] for a middle-qubit flip.

Syndrome 0 means commuting (+1); 1 means anticommuting (−1). Generators must be commuting Hermitian Pauli matrices on the same 1–9 qubits. Consistent redundancy is accepted; a group containing −I is rejected. These operations describe code spaces and Pauli-error syndromes, not automatic encoding circuits.

Paste stabilizer groups

stabilizer_projector(⟨XX, ZZ⟩) accepts the group-generator notation from the lessons. Inside these brackets, XX means X⊗X. ASCII <XX,ZZ> and LaTeX angle brackets work too.

Use stabilizer_syndrome(⟨ZZI, IZZ⟩, pauli(IXI)) to detect a middle-qubit flip. Pauli words may have a leading sign; the generators must commute and define a nonempty code space. Bra–ket notation elsewhere keeps its usual meaning.

Code distance and parameters

stabilizer_parameters(⟨XZZXI,IXZZX,XIXZZ,ZXIXZ⟩) returns [5 1 3]: five physical qubits, one logical qubit, distance three. These are the entries of [[n,k,d]] code notation.

stabilizer_distance(⟨ZZI,IZZ⟩) returns 1: the repetition code protects bit flips, but a single Z is an undetected logical error. Distance searches all Pauli errors exactly on 1–9 qubits and excludes stabilizers, including their scalar multiples. At least one encoded qubit is required; k=0 stabilizer-state distance is not defined by these functions.

Correct a measured syndrome

stabilizer_correction(⟨ZZI,IZZ⟩,[1,1]) returns the middle-qubit flip IXI. Apply the returned matrix to the errored state. Entries are sign bits in generator order: 0 means +1, 1 means −1. For one generator, a scalar bit works too.

The search finds a lowest-weight Pauli correction on 1–9 qubits. Redundant checks must give a consistent syndrome. Zero syndrome returns identity. A correction can leave a logical error when the actual error exceeds the code’s correction capability; the syndrome does not uniquely identify arbitrary errors. This produces a correction matrix, not an automatic measurement circuit.

Qiskit-style Pauli labels

Pauli('-1jXYZ')|000⟩ produces |110⟩. Labels support single or double quotes, an optional sign and 1, and i or j for an imaginary phase. The letters are tensor factors from left to right; 1–9 letters are supported.

Qiskit calls the rightmost factor qubit zero. This app’s circuit editor calls the leftmost factor wire zero. The matrix represented by the same label is unchanged. Pauli labels now construct their matrices directly for faster calculations.

CSS codes from binary checks

css_generators(Hx,Hz) converts binary check rows into X stabilizers followed by Z stabilizers. Feed the result into the stabilizer dimension, distance, syndrome or correction functions. The matrices must have equal width and satisfy Hx Hzᵀ = 0 over GF(2).

css_state([1,1],[1,1],0) constructs a Bell state. In general, the third argument is a basis index satisfying the Z checks; the result is the normalized uniform superposition over its coset under the X-check row space.

Use [] for an absent check type. At least one row must specify the width. Limits: 1–9 qubits and 32 total rows. Redundant checks are allowed. Columns run from the leftmost tensor factor to the rightmost.

Build a CSS preparation circuit

In the composer choose Build → CSS code state. Enter binary X and Z check matrices and a representative bitstring, with q0 first. The defaults prepare Steane logical |0⟩; 0000111 prepares logical |1⟩. Use [] for an absent check type.

The builder prepares the selected coset state from |0…0⟩ using H, CNOT and X gates. It supports 1–8 qubits and 32 total check rows. The result can be edited, undone, saved and exported to OpenQASM. Invalid checks leave the existing circuit intact. This prepares a selected state; it does not encode an unknown logical input.

Encode logical states with CSS codes

css_encoder(Hx,Hz) returns an exact encoding isometry V. Multiply V by a logical ket to encode its complex amplitudes. For example, css_encoder([],[1,1,0;0,1,1])|i⟩ gives (|000⟩+i|111⟩)/√2.

V†V is identity and VV† is the code-space projector. Encode a density matrix as VρV†. The adjoint decodes states in the code space; apply error correction first when needed.

The logical basis greedily uses the smallest unused binary words satisfying the Z checks, modulo the X-check row space. The first selected word labels the least significant logical bit. Limits match css_generators: 1–9 qubits and 32 total rows. The matrix is an isometry.

For an editable unitary circuit choose Build → CSS encoding circuit. The first k wires carry the logical input; the remaining wires start at zero. Select Append to my current logical-input circuit to keep a prepared k-qubit input. For Steane |i⟩, prepare H then S on one qubit and append the default encoder.

The H/CNOT/SWAP circuit matches the same logical basis, supports 1–8 physical qubits and 64 total steps, and can be undone, saved and exported. Appending preserves noise channels, although OpenQASM export rejects those channels. Incompatible registers or checks leave the old circuit intact.

Cirq power gates

Use XPowGate(exponent=1/2), ZPowGate(exponent=1/4) and CZPowGate(exponent=1/2) for SX, T and controlled-S. These calls use half-turn exponents as in the qBraid Cirq VQE example. The exponent defaults to 1.

The optional global_shift defaults to 0 and multiplies the gate by exp(i π exponent global_shift). In particular XPowGate(exponent=t,global_shift=-1/2) equals Rx(πt). Retaining this phase matters when controlling the gate. Positional arguments (exponent, shift) also work. These are calculator expressions; Python statements and the cirq namespace are not executed.

Compare measurement distributions

hellinger_fidelity([100,0,0,100],[90,10,10,90]) returns 0.9 for ideal and noisy Bell counts. hellinger_distance(p,q) measures their distance: zero for identical distributions, one for disjoint support.

Inputs are aligned row or column vectors of probabilities or counts, normalized separately. Put outcomes in the same order and use zero for missing outcomes. Entries must be finite, nonnegative real numbers with positive total weight; at most 1024 outcomes are supported. Python count dictionaries are not accepted.

Fidelity is (Σ√(pᵢqᵢ))² and distance is √(Σ(√pᵢ−√qᵢ)²/2), using normalized weights. These describe measurement distributions; agreement in one measurement basis does not prove equal quantum states.

Binary numerals

In phase estimation, 0.100₂ means one half. You can also enter 0.100_2 or 0.100_{2}. Integer and fractional parts are evaluated exactly: 10.101₂ is 21/8. A leading minus sign works normally.

Use a finite sequence of at most 1024 binary digits, with at most one radix point. Powers bind to the whole numeral: 0.1_2^2 is 1/4. Ordinary decimal values and dimension-qualified kets retain their meaning. Repeating expansions, symbolic digits, other radix subscripts and a radix attached outside parentheses are not supported.

Indexed spin operators

Paste expressions such as 5.907-2.1433*spin.x(0)*spin.x(1)-2.1433*spin.y(0)*spin.y(1)+0.21829*spin.z(0)-6.125*spin.z(1). Factors spin.i, spin.x, spin.y and spin.z act on indexed qubits. Scalar additions are identity offsets; 1+spin.z(0) is diag(2,0).

All spin factors in the pasted expression share a full register from index 0 through the largest index used. CUDA-Q index 0 is the rightmost tensor factor, unlike composer wire 0. For example, spin.z(0)*spin.i(1) gives I ⊗ Z. Include an identity factor to extend the register. Indices must be literal integers from 0 to 8.

The qualified spellings cudaq.spin.x(0), cudaq::spin::x(0) and cudaq::spin_op::x(0) also work. This evaluates operator expressions; Python/C++ statements, object methods and CUDA-Q kernels are not executed. The app embeds skipped indices as identity factors rather than compressing the active-degree set.

Hermitian matrix order

A ≥ B means that A − B is positive semidefinite. For example, [1,-1;-1,1] ≥ 0 returns 1 even though it contains negative entries. [1,2;2,1] ≥ 0 returns 0. Strict A > B requires A − B to be positive definite, so a singular projector is ≥ 0 but is not > 0.

Use ASCII >= and <=, Unicode ≥, ≤, ≽, ≼, ⪰, ⪯, ≻, ≺, or TeX \succeq, \preceq, \succcurlyeq, \preccurlyeq, \succ, \prec. Scalars beside matrices mean a scalar times the matching identity: 0 ≤ density(|i⟩) ≤ I returns 1. Scalar comparisons and equality retain their ordinary meanings.

Operands must be Hermitian square matrices of matching dimension, at most 64. The exact evaluator checks signs through Schur complements, including zero pivots; it does not discard small eigenvalues using a numerical tolerance. Unresolved signs, incompatible dimensions and unprovable Hermiticity produce errors. Approximate inputs retain their numerical limitations. This tests a supplied operator inequality; it does not solve a semidefinite optimization problem.
