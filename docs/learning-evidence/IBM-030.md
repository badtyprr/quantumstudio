### Expected query cost of the positive-iteration schedule

For 0 < s < N, each fresh trial starts in the uniform state and uses independent randomness. Its success probability averaged over the allowed iteration counts is

```text
P(T) = (1/T) ∑[t=1..T] sin²((2t+1)θ)
     = 1/2 − sin(2Tθ) cos((2T+4)θ) / (2T sin(2θ)).
```

The second equality follows by summing the cosines of (4t+2)θ as a geometric series. For T ≥ 2/sin(2θ), success is at least 1/4. Each trial costs at most T Grover queries plus one oracle query to check the measured word. From any starting limit L, the ceiling update gives Tⱼ ≤ (L+4)(5/4)ʲ after j increases. Thus the expected cost after reaching the threshold is O(L), since each successive term is bounded by a constant times (15/16)ʲ L.

When s ≤ N/2, sin(2θ) = 2√((s/N)(1−s/N)) ≥ √(2s/N). The first limit reaching the threshold is O(√(N/s)). Earlier limits grow by at least a factor of 5/4, so their total cost, including verification, is also O(√(N/s)).

For s > N/2, write δ = π/2−θ. If δ ≥ π/16 the threshold is bounded by a constant. Otherwise, while (2T+1)δ ≤ π/4, every allowed trial succeeds with probability at least 1/2, because its success probability is cos²((2t+1)δ). The expected cost of these early trials is bounded by a constant times the sum of (5/8)ʲ. Let L be the first limit above this early range. Its size is of order 1/δ. The probability of reaching it times L is bounded by a constant, by the same geometric estimate. The threshold 2/sin(2δ) is also of order 1/δ, so only a bounded number of limit increases separate L from the late range. The expected contribution from these intermediate and late trials is consequently O(1). If all words are marked, the first verified measurement always succeeds. Together the cases establish expected O(√(N/s)) queries whenever a solution exists.

For an empty marked set every verification fails. A query budget makes the lecture’s optional no-solution exit precise. For example, the preceding bound supplies an absolute C with expected cost at most C√N on every nonempty instance. Ending the search after a budget of 3C√N queries gives an empty instance O(√N) cost, and Markov’s inequality bounds the probability of missing an existing solution by 1/3. This is a bounded-error interpretation of the lecture. Its unspecified constant and stopping rule are separate from the eight-trial replay parameter.
