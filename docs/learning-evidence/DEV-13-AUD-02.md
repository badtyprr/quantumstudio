## Proposed import/execution contract (not implemented)

1. **Inspect before execute.** Importing .ipynb initially only parses JSON and displays source/cell IDs, dependencies, setup, file inputs and requested capabilities. Preserve original bytes and notebook order; ignore stored outputs as evidence. Do not execute merely by opening, render arbitrary HTML unsafely, or auto-install %pip cells. A Python program and a selected-cell extraction are separate route kinds. Every omitted/rewritten cell or QASM export is recorded as an adaptation.
2. **Request envelope.** Versioned JSON contains request ID, route (whole-notebook/direct-program/manual-qasm), immutable source hashes/revision, ordered cell IDs or entrypoint, input-file manifest, interpreter/platform/lock hash, local backend, seed/shots, timeout/memory/output limits and desired result type. A selected cell route must declare preceding state dependencies. No hidden shared kernel state. Unsupported magics, provider calls, pulse, QIR and CUDA-Q return explicit unsupported-capability results; never silently drop them or substitute a simulator for a service.
3. **Environment lifecycle.** Build environments in staging keyed by interpreter ABI/platform plus lock digest; install only reviewed hash-locked wheels, run import/pip checks, then mark ready. Failed staging never becomes reusable. One fresh process and writable job directory per run; immutable source/input copies and environment reused read-only. Environment reuse does not imply result caching. Record lock, executable and package identities. Do not inherit provider credentials. Before supporting arbitrary notebook code, enforce OS-level restricted filesystem, no-network and resource/process limits; static import scanning and a venv are not enforcement. General notebook execution remains a later milestone.
4. **Results.** Return bounded JSON metadata plus hashed external artifacts: status, provenance, route/adaptations, backend, elapsed time, stdout/stderr truncation flags, ordered cells, numeric dtype, explicit qubit/bit/register order, state vector or density dimensions, shot count/seed/counts, observable definitions/units and artifact hashes. Reject pickle/arbitrary Python objects. Encode complex values as finite real/imaginary pairs. Distinguish counts, probabilities, quasi-probabilities, amplitudes, unitary matrices, expectation estimates and images. Partial outputs from failed/cancelled jobs are labelled incomplete and cannot be imported as successful results.
5. **Verification boundary.** Parent validates schema, finite values, dimensions, normalization, nonnegative integer counts and shot totals; order conversion must be explicit. Small state tests compare all amplitudes up to one justified global phase; operator tests must not phase-align columns independently. Counts use predeclared statistical tolerances/support, with nonsymmetric bit-order witnesses. Observables need independent analytic or dense references and errors/uncertainty. Conversion graphs need independent operator checks; rendered circuits/plots are not semantic proof. Generated OpenQASM passes the existing importer with include/hash provenance and its supported-domain checks before app acceptance. Never silently fix missing preparation, endianness, or unsupported operations.
6. **Errors and cancellation.** Distinct statuses: invalid-source/hash, environment-build/dependency failure, unsupported-capability, Python exception (cell/line/type), backend error, verification failure, timed-out, cancelled and completed. Capture bounded traceback plus logs; do not convert skipped imports or swallowed assertions to success. A process supervisor must enforce wall-clock/output/memory limits, signal cooperative interrupt, then terminate the complete owned process tree after a grace period (Windows Job Object or equivalent), reap it, and commit a terminal result atomically. Job IDs prevent late results attaching to a new run. A cancelled local process is not proof of remote job cancellation; provider lifecycle is expressly excluded. Supervisor/cancellation/resource enforcement is proposed only, not implemented or tested by this proof.
7. **Retention.** Keep source snapshots, lock/wheel manifest, run records and artifacts outside disposable checkouts. Interrupted job directories can be cleaned only after evidence retention and all children are reaped. Shared environments need reference counting/leases before eviction. For this repository, preserve and verify unique commits, patches and nongenerated files before deletion; resolve targets beneath .tools and preserve root dist. This checkout remains necessary for review; no cleanup deletion is performed.
